# あそべる日本地図

都道府県をドラッグして動かせる日本地図です。動かすと、その都道府県にちなんだ演出が起きます
（愛媛ならみかんジュースが吹き出す、東京なら東京タワーが生えてくる、など）。
47都道府県 × 各5種類 = 235種類。ドラッグするたびに順番に切り替わります。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要）。

- ドラッグ: 都道府県を動かす＆演出
- ダブルクリック: その都道府県だけ元の位置へ
- 「元に戻す」: 全部元の位置へ
- 右上の「発見」: 見つけた演出の数（ブラウザに保存）

## ファイル

- `js/map-data.js` — 都道府県のSVGパス（[dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson` を `tools/convert-map.js` で簡略化）
- `js/effects-data.js` — 都道府県ごとの演出5種類（ここを編集すると演出を変えられます）
- `js/main.js` — ドラッグと演出エンジン
